# Paleta AGUANTA

| Nombre | HEX | RGB | Variable CSS | Uso |
|---|---|---|---|---|
| **Tinta** | `#0B0B0C` | 11, 11, 12 | `--tinta` | Fondo principal de hero y pie, texto sobre claro, bordes. |
| **Hueso** | `#F4F1EA` | 244, 241, 234 | `--hueso` | Fondo de página, texto sobre tinta. Nunca blanco puro. |
| **Rojo** | `#FF3B1F` | 255, 59, 31 | `--rojo` | Acento: la palabra que duele (MÁS), tachados, barra de anuncio. |
| **Lima** | `#C8FF00` | 200, 255, 0 | `--lima` | Acción: botones, pegatinas, progreso, foco. |
| Rojo texto | `#C9270D` | 201, 39, 13 | `--rojo-texto` | Solo para texto rojo **pequeño** sobre hueso (cumple AA). |
| Gris | `#5C5A55` | 92, 90, 85 | `--gris` | Texto secundario sobre hueso. |

## Proporción
Más o menos **45 % tinta · 40 % hueso · 10 % rojo · 5 % lima**. El rojo y la lima son acentos, no fondos de página (salvo una sección o una marquesina).

## Combinaciones y contraste (WCAG)

| Texto / fondo | Ratio | Uso permitido |
|---|---|---|
| Hueso / Tinta | 17,4:1 | Todo |
| Tinta / Lima | 16,6:1 | Todo (botones) |
| Tinta / Rojo | 5,5:1 | Todo (barra de anuncio, pegatinas) |
| Rojo / Tinta | 5,5:1 | Todo |
| Gris / Hueso | 6,1:1 | Texto secundario |
| Rojo texto / Hueso | 4,9:1 | Texto pequeño |
| Rojo / Hueso | 3,2:1 | **Solo titulares grandes** (≥ 24 px) |
| Rojo / Lima | 3,0:1 | **Nunca para texto.** Nunca juntos sin tinta en medio. |

## Impresión
Los PNG de impresión usan los HEX tal cual. DTG y sublimación no reproducen el lima fluorescente con la misma intensidad que una pantalla: pide muestra antes de lanzar (sobre todo leggings y shorts).
